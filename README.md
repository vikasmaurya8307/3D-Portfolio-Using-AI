# 🤖 3D-Portfolio Using AI | Vikas Maurya

Welcome to my next-generation personal portfolio. This project is a fusion of **Data Analytics expertise** and **AI-driven web development**, creating an immersive 3D experience to showcase my technical journey.

## 🚀 Live Demo
[Explore the 3D Portfolio](https://vikasmaurya8307.github.io/3D-Portfolio-Using-AI/)

## 🛠️ Tech Stack
- **Core Engine:** Three.js (WebGL) for interactive 3D environments.
- **AI-Augmented:** Built using advanced Prompt Engineering for optimized rendering and custom UI logic.
- **Styling:** Modern CSS3 (Cyberpunk Aesthetic, Glassmorphism, and Clip-path geometry).
- **Data Analyst Tools:** Highlighting projects built with **Python, SQL, Excel, and Power BI**.

## ✨ Key Features
- **Interactive Particle System:** A dynamic, mouse-tracking background built with Three.js.
- **AI-Optimized Code:** Leveraged AI to refine animations and ensure smooth performance across devices.
- **Project Showcase:** Direct links to my **Inventory Management System** and other data-driven projects.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
